# CLI File Renamer

Небольшая консольная утилита на Python для пакетного переименования файлов в указанной директории прямо из командной строки. Проект создан в качестве практической работы по курсу базового Python.

## 🌟 Особенности (Features)

* **Передача аргументов через CLI:** Быстрый запуск переименования одной командой с передачей пути к папке и базового имени файла через `sys.argv`.
* **Генерация уникальных имён:** Добавление случайного числового идентификатора (от 0 до 10000) к новому имени файла.
* **Сохранение расширений:** Оригинальные расширения файлов (`.png`, `.txt` и т.д.) сохраняются автоматически.
* **Отказоустойчивость и безопасность:** 
  * Валидация аргументов командной строки.
  * Проверка существования директории.
  * Безопасная обработка исключений файловой системы (`FileNotFoundError`, `FileExistsError`) для каждого файла без остановки скрипта.
* **Кроссплатформенность:** Использование библиотеки `pathlib` обеспечивает корректную работу с путями на Windows, Linux и macOS.

## 🛠 Технологический стек

* **Python 3.8+**
* Стандартные библиотеки: `pathlib`, `sys`, `random` (не требует установки сторонних зависимостей).

## 🚀 Быстрый старт

### Требования
Установленный интерпретатор Python версии 3.8 или выше.

### Инструкция по запуску

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/OkeyLooft/file-renamer.git
   cd file-renamer
2. **Запустите скрипт, передав путь к папке и новое имя:**
   `python main.py /путь/к/папке новое_имя`
3. **Пример использования:**
			`python main.py ./my_photos photo_`
