# CLI File Renamer

Небольшая консольная утилита на Python для пакетного переименования файлов в указанной директории. Проект создан в качестве итоговой практической работы по курсу базового Python.

## 🌟 Особенности (Features)

* **Интерактивный ввод пути**: автоматическое определение домашней директории пользователя (`Path.home()`) с валидацией существования указанной папки.
* **Безопасное переименование**: генерация случайных идентификаторов с защитой от перезаписи существующих файлов.
* **Работа с файловой системой**: фильтрация директорий и обработка только целевых файлов с сохранением их оригинальных расширений.
* **Кроссплатформенность**: благодаря библиотеке `pathlib` скрипт корректно работает на Windows, Linux и macOS.

## 🛠 Технологический стек

* **Python 3.10+**
* Стандартные библиотеки: `pathlib`, `random`
