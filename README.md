# CLI File Renamer

Небольшая консольная утилита на Python для пакетного переименования файлов в указанной директории прямо из строки вызова. Проект создан в качестве практической работы по курсу базового Python.

## 🌟 Особенности (Features)

* **Передача аргументов через CLI**: запуск переименования одной командой с передачей пути и базового имени файла прямо в аргументах `sys.argv`.
* **Вариативность наименования**: поддержка кастомных префиксов и генерация уникальных имён для файлов.
* **Сохранение расширений**: оригинальные расширения файлов (`.png`, `.txt` и т.д.) сохраняются автоматически.
* **Кроссплатформенность**: благодаря библиотеке `pathlib` утилита корректно обрабатывает пути на Windows, Linux и macOS.

## 🛠 Технологический стек

* **Python 3.10+**
* Стандартные библиотеки: `pathlib`, `sys`, `random`
